# Glossary of Terms

In no particular order:

| Terms      | Definition                                                     |
| ---------- | -------------------------------------------------------------- |
| Icara      | The brand                                                      |
| Profile    | User's beauty metadata and brand/persona                       |
| Brand      | User community's brand                                         |
| Item       | Beauty item                                                    |
| Storage    | A list of items that user has bought but hasn't opened.        |
| Collection | A list of items that user has opened.                          |
| Archive    | A list of items that user has discarded, for whatever reasons. |
| Wishlist?  | A list of items that user hasn't bought, but wants.            |
